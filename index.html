How I work

The same four steps, whether it’s a B2B website or a dance studio.

  1. 01 · Research Find the audience and the gap Keyword research, competitor checks and audience notes before anything gets made. e.g. Golden Owl keyword plan
  2. 02 · Plan Build the funnel and the calendar Channels, budget, content plan and the one number each stage has to move. e.g. Alira TikTok content plans
  3. 03 · Launch Ship content, ads and events Campaigns, posts, landing pages and booths, run with designers, devs and partners. e.g. Spartan x Bach Khoa booth
  4. 04 · Measure Read the numbers, then iterate A/B tests, rankings and lead counts decide what gets more budget next month. e.g. Golden Owl ad creative tests
